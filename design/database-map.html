What the schema enforces

Four rules the database keeps for us

Every row has an owner

User data carries user_id, and a privacy rule lets only that account read it (T26). Deleting an account deletes its rows.

No pointing at someone else's person

Concierge tables link to a person by (person_id, user_id) together, so a row can only name one of its own owner's people.

Products meet at people only

Lists and the concierge share no foreign keys except person_links (T19). A gift idea names a list gift by id and reads it through the lists module's functions.

An order keeps its own address

An order belongs to the idea it bought and the round it came from, and its shipping address is copied onto it, so a later edit never changes where a placed order went.
